# Garage universe

Run from this folder with Python 3.11+ (standard library only):

```sh
python run.py sample.json
```

Maps radar node states to a cosmetic planet scene: orbit index, label, color, and original status. Accepts saved network-radar output. No graphics renderer or invented physical measurements.

Use `python run.py --help` for options. See [the garage run guide](../../README.md) for deployment boundaries.
