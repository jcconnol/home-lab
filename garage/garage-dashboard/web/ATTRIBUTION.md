# Data and map attribution

`land.json` contains equirectangular drawing coordinates derived from Natural Earth's 1:110m land polygons. Natural Earth map data is public domain. Source: [Natural Earth vector data](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson), [terms](https://www.naturalearthdata.com/about/terms-of-use/).

Weather: Open-Meteo (CC BY 4.0). Air quality: CAMS via Open-Meteo (CC BY 4.0). Aircraft: adsb.lol (ODbL 1.0). ISS: CelesTrak orbital elements and Skyfield calculations. Solar system: JPL DE421/Skyfield and NASA JPL Horizons. Source labels, timestamps, and coverage limitations are shown in the interface.
